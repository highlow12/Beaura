# Applying Rules to the Structure of an Expression

Differentiation rules are not mutually exclusive choices; they help you read the structure of an expression. If a product contains a composite function, start with the outer structure and apply the needed rule to each part. Differentiating both factors and multiplying the results does not account for both ways the product can change.

For example, in `y=x² sin x`, let `f=x²` and `g=sin x`; the product rule gives `y′=2x sin x+x² cos x`. In contrast, `y=(x²+1)³` is a composite function with an outer cube and inner `x²+1`, so `y′=3(x²+1)²·2x`.

Common errors include writing `(fg)′=f′g′` or omitting the inner derivative in the chain rule. Before differentiating, label the outer function, inner function, and products in the expression to keep track of each contribution to the change.
