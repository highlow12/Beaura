# Packets and the Layer Model

For different devices and operating systems to communicate, they need shared rules for how data is represented and what each step is responsible for.

A protocol is an agreed set of rules for message formats and order. A packet is a unit of data divided into a header and payload for transmission. A layered model separates addressing, delivery, and application-level meaning.

In this lesson, we will follow how packets acquire addresses and state at each layer, and distinguish key networking terms.
