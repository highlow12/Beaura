# What Is a Proposition?

A proposition is **a statement that can be determined to be true or false**. For example, `2 + 3 = 5` is a true proposition, while `7 is even` is a false proposition. A statement must have exactly one truth value: true or false.

By contrast, a command such as “Close the door” or a question such as “What time is it?” is not a proposition. A statement with an unspecified variable, such as `x + 1 = 3`, is also not a proposition because its truth cannot be determined yet.

In computer science, conditions in code and search queries are also evaluated as true or false, like propositions. Discrete mathematics provides tools for reasoning precisely about these logical objects.
