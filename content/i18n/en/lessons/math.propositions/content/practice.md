# Reading Conditions as Logical Expressions

The implication `P → Q` means “if P, then Q.” The implication is defined as false only when P is true and Q is false; in all other cases, it is true.

Two propositions are equivalent if they always have the same truth value, written as `P ↔ Q`. To evaluate a logical expression, first determine the truth value of each component proposition, then calculate the result one operation at a time.
