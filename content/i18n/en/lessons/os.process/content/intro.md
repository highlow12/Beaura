# Processes and Execution Units

An executable on disk is only data. To run it on the CPU, the operating system must create a process with resources and state.

A process is an operating-system-managed unit that includes a running program’s address space, register state, open files, and other resources. The same program can run as multiple processes.

In this lesson, we will follow which resources an operating-system abstraction hides and where it enforces boundaries and checks.
