# Rules for Inputs and Outputs

A function f assigns exactly one output f(x) to each input x. On a graph, the horizontal axis represents the input and the vertical axis the output; if one x-value has multiple y-values, the graph is not a function.

The domain is the set of allowed inputs, the codomain is the full set designated for outputs, and the range is the set of outputs that actually occur. Therefore, the range is a subset of the codomain. Restricting the domain can change the graph and properties of the same expression.
