# DNS Name Resolution

People can remember names such as `example.com`, but packets need a destination IP address, so a system is needed to translate names into addresses.

DNS is a distributed naming system that manages domain names and records hierarchically. A resolver checks its cache first and, if needed, queries the root, TLD, and authoritative servers.

In this lesson, we will follow how packets acquire addresses and state at each layer, and distinguish key networking terms.
