# Algorithms That Decide

A problem or language is decidable if there is an algorithm that halts on every input and returns a yes/no answer. It returns yes for an input in the language and no otherwise, and must finish in a finite number of steps in either case.

A decider must both return the correct answer and guarantee termination. A machine that halts only on inputs in the language and may run forever on other inputs can be a recognizer, but is not a decider.
