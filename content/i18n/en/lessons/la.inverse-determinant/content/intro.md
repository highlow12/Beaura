# Can a Transformation Be Reversed?

The inverse of a square matrix `A`, written `A⁻¹`, satisfies `AA⁻¹ = A⁻¹A = I`. If the inverse exists, after applying the transform `A`, you can use the inverse to recover the original vector.

The determinant of a 2×2 matrix `[[a, b], [c, d]]` is `ad − bc`. If the determinant is 0, the columns are linearly dependent, information has been collapsed, and no inverse exists.
