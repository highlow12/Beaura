# Read a Distribution Table

A table of a random variable’s values and probabilities lets you calculate its expected value and variance. Even for the same outcomes, X’s distribution depends on the numerical rule you define.

The cumulative distribution function F(x)=P(X≤x) adds up the probabilities of values at or below x. Treat omitted values in a table as having probability 0, and check first that the probabilities sum to 1.
