# The Measurement Rule Changes the Distribution

A random variable is a model that specifies how to record outcomes numerically. Different random variables on the same sample space can capture different information and have different distributions, so first clarify what the variable means and what values it can take.

Record the outcomes of two fair dice as ordered pairs, and let `X` be their sum. `P(X=2)=1/36`, while `P(X=7)=6/36` because six pairs produce 7. Looking only at the values `2` and `7` might make them seem equally likely, but the PMF reflects how many original outcomes map to each value.

A common mistake is to treat a random variable as the outcome itself or to assume that all its numerical values are equally likely. A random variable maps outcomes to numbers, and the probability of a value is the sum of the probabilities of the outcomes mapped to it.
