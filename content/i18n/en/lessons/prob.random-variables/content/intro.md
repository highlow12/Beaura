# Turn Outcomes into Numbers

A random variable X is a function that assigns a number to each experiment outcome; it is not the outcome itself. If X counts the heads in two coin flips, it can be 0, 1, or 2.

A discrete random variable has a probability mass function (PMF) that assigns P(X=x) to each value x. Each possible value must have a nonnegative probability, and the probabilities must sum to 1.
