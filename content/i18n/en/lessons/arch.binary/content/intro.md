# The Bit, a Basic Unit of Computing

A bit is a unit of information that stores one 0 or 1. Multiple bits can represent an integer in binary. From right to left, each bit has a power-of-two place value such as 1, 2, 4, and 8.

For example, 101 is 1×4 + 0×2 + 1×1, so it is 5 in decimal. The same bits can mean different things depending on the chosen convention, such as a signed integer, character, or color.
