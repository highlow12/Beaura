## Each Bit Position Has a Different Value

Each binary position has a power-of-two value, increasing from right to left as 1, 2, 4, 8, 16, and so on. Add the values at positions containing 1 to convert a binary number to decimal.

For example, `10110₂` is `16 + 4 + 2 = 22`. To convert a decimal number to binary, consider which powers of 2 add up to that value.

These place values also appear in bitwise operations and memory addresses, so practice reading what each bit represents instead of only memorizing the pattern.
