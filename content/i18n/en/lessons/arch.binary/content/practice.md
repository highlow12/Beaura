## Bytes and Representable Ranges

A group of 8 bits is called a byte. More bits allow more distinct combinations, but the signedness and data-type rules determine the value range.

Hexadecimal is a compact way to write binary values. One hexadecimal digit corresponds to 4 bits, making long bit patterns easier to read and write.

An unsigned 8-bit integer has 2⁸ = 256 combinations and represents values from 0 to 255. The maximum value is one less than the number of combinations.
