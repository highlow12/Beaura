# Store Multiple Values in a List

A list is a data type that groups values in order. The first item has index 0; use square brackets to read a particular position, as in `scores[1]`.

~~~python
scores = [80, 95, 70]
best = scores[1]
~~~

Lists are mutable. You can change an existing position, as in `scores[0] = 85`, and iterate over the same list in a loop.
