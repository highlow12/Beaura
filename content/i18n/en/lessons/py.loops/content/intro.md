# Repeat Work with Loops

A loop lets you write a repeated rule once instead of writing the same operation many times. Use `for` to take items one by one from an ordered value such as a list, and `while` to keep running as long as a condition is true.

~~~python
for name in ["민", "준"]:
    print(name)
~~~

The indented block runs once per iteration. `name` refers to "민" in the first iteration and "준" in the second.
