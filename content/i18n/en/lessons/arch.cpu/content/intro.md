# The Order in Which a CPU Executes Instructions

The CPU fetches an instruction from memory, decodes what it does, then executes it using the ALU, registers, and other components. It repeats this cycle rapidly to run a program.

The CPU has storage with different roles, such as the program counter, which points to an instruction address, and registers, which hold values during calculations. Distinguishing these small storage locations inside the CPU makes it easier to picture how one line of code runs.
