## View Trees as Paths and Subtrees

In a tree, every node except the root has one parent. Following edges from parent to child reveals ancestor and descendant relationships.

A node together with all of its descendants forms a `subtree`. When solving a problem on a large tree, you can treat the left and right subtrees of a node as smaller problems of the same kind.

The number of edges from the root to a node is its depth, so the root has depth 0 and its children have depth 1.
