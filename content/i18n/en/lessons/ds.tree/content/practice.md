## Depth and Binary Trees

The number of edges traversed from the root to a node is its depth. The path length to the deepest node is used to understand the tree’s height.

In a binary tree, each node has at most two children. The meanings of the left and right children depend on the problem and should be made clear when defining traversal order.

The following questions represent nodes with Python dictionaries. `{"value": "A"}` maps the label `"value"` to `"A"`. Read that value with `node["value"]`. If children are also stored as dictionaries, `tree["left"]["value"]` reads the left child’s value.
