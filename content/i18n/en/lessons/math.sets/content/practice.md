# Calculating Set Operations

The union A ∪ B collects elements that belong to at least one of the two sets. The intersection A ∩ B keeps only elements shared by both sets, and the difference A − B keeps elements in A that are not in B.

For example, if A={1,2,3} and B={3,4}, then A∪B={1,2,3,4}, A∩B={3}, and A−B={1,2}. Remove duplicates in the result and check which set is the starting point for the difference.
