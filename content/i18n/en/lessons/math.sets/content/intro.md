# Representing Collections of Elements

A set is a collection of elements without regard to order or repetition. For A = {1, 2, 3}, we write 2 ∈ A, and listing the same element more than once still counts it only once in a set.

If every element of A is also in B, we write A ⊆ B. Distinguish membership of a single element in a set (∈) from the inclusion of one whole set in another (⊆).
