# Queues: First In, First Out

A queue is a data structure that enqueues at one end and dequeues at the other. It follows FIFO (First In, First Out) order: the value added first is removed first.

Think of people waiting in a line. New tasks join at the back, and tasks to be processed leave from the front. A web server’s task queue or a printer’s job list can also be described with this model.
