# Dimensions and Calculation Order

The product of a 2×3 matrix and a 3×4 matrix is a 2×4 matrix. To calculate each result entry, multiply and add the components of a row and a column, each of length 3.

When multiplying several matrices, the associative law `(AB)C = A(BC)` holds, but the commutative law `AB = BA` generally does not. Writing down the dimensions first helps prevent errors.
