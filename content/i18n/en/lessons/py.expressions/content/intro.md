# Values and Expressions

A value is something a program can work with directly, such as the number 7, the string `"Ada"`, or the Boolean `True`. A value written directly in code is called a literal; values are the inputs to calculations.

An expression is a piece of code that combines values and operators and evaluates to one result, such as `2 + 3`. You can store an expression’s result in a variable or pass it as a function argument.
