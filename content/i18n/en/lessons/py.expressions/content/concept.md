## Expressions Produce Results

An expression produces a value when it is evaluated. `score + bonus` reads the values referenced by the two names, adds them, and produces a result. The name `score` by itself is also a simple expression that reads its current value.

By contrast, `score = 10` is an assignment statement that binds a value to a name. Distinguishing expressions from statements makes it easier to see which parts produce values and which carry out program actions.
