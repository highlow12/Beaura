# Software That Manages Data

A database is an organized collection for storing and retrieving data according to rules. A DBMS (Database Management System) hides the details of storage devices and provides functions such as queries, concurrent access, permissions, and recovery.

A schema describes the data structure, including table columns, data types, and constraints. An application sends queries to a DBMS and uses the results, but does not need to manage the byte layout of files or update indexes directly.
