# A Function That Preserves Structure

A linear transformation `T` is a function that satisfies `T(u + v) = T(u) + T(v)` and `T(cu) = cT(u)`. This means it maps the origin to itself and preserves linear combinations of vectors.

A 2D linear transformation can be represented by a 2×2 matrix whose columns are the images of the standard basis vectors `e₁` and `e₂`. Multiplying a vector by the matrix gives the transformed vector.
