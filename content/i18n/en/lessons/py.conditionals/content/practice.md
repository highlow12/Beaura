## Practice Comparison Operators

Comparison operators compare two values and produce `True` or `False`.

| Operator | Meaning |
| ------ | ----------------------------------- |
| `>=` | The left value is greater than or equal to the right value |
| `==` | The two values are equal |
| `<` | The left value is less than the right value |

A conditional uses this result to choose an execution path. First predict the comparison result, then check which block runs.
