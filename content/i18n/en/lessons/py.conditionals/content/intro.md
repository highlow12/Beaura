# Choose What to Run with Conditionals

A program can run different code depending on the result of a condition. In Python, write the condition after `if` and indent the code that should run when it is true.

~~~python
score = 75

if score >= 60:
    print("pass")
else:
    print("retry")
~~~

Because `score >= 60` is true, this code prints `pass`. The `else` block runs when the condition is false.
