# Vectors Whose Direction Survives a Transform

An eigenvector `v` of matrix `A` is a nonzero vector that satisfies `Av = λv`. The transformed result is always a scalar multiple of `v`. If `λ > 0`, it points in the same direction; if `λ < 0`, it points in the opposite direction; and if `λ = 0`, it becomes the zero vector.

`λ` is called an eigenvalue. Several eigenvectors can correspond to the same eigenvalue. The zero vector is excluded because it satisfies the equation for every `λ`.
