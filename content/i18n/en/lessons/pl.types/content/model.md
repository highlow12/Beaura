# Checking and Inference

Type checking verifies that the input and result types of an operation follow the language's rules. Type inference computes types from assignments and function calls, so programmers do not need to write every type annotation. A program's type constraints still need to be checked even when types are inferred.

Use the phrase “strongly typed” carefully because it is not one formal axis. More specific ways to compare languages include whether conversions happen implicitly, when type errors are rejected, and how runtime safety is guaranteed.
