# Calculate Probability by Counting Events

For a die, the even-outcomes event is {2,4,6}, so P(even)=3/6=1/2. If outcomes are not equally likely, add their probabilities instead of simply counting them.

The complement Aᶜ is the set of outcomes where A does not occur, and P(Aᶜ)=1−P(A). Drawing events as sets makes overlaps and omitted outcomes easier to spot.
