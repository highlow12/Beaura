# Collecting Possible Outcomes

The set of all possible outcomes of a probability experiment is called the sample space Ω. An event is a set of outcomes of interest, so it can be represented as a subset of Ω.

When there are finitely many equally likely outcomes, the probability of event A is P(A)=|A|/|Ω|. Probability ranges from 0 to 1; the whole sample space Ω has probability 1, and an impossible event has probability 0.
