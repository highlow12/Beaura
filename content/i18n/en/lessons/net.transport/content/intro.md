# UDP and Ports

When multiple programs on one device use the network at the same time, an IP address alone cannot identify the receiving process.

A port number identifies a transport endpoint on a host. UDP includes ports, length, and other fields in each datagram for fast delivery, but does not guarantee ordering, retransmission, or congestion control by default.

In this lesson, we will follow how packets acquire addresses and state at each layer, and distinguish key networking terms.
