# Include Randomness in the Analysis

A randomized algorithm uses random numbers or samples to choose an execution path or input. Its path may vary across runs on the same input, so its performance is analyzed using expected running time or failure probability.

If keys are distributed uniformly among m slots in a hash table, distinct keys can still land in the same slot, causing a collision. A good hash function spreads collisions evenly to reduce average cost rather than eliminating them.
