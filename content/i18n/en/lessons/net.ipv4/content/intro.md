# IP Addresses and IPv4 Packets

To travel across multiple links on the internet, a packet needs an address with a wider scope than the MAC address of the neighboring device.

An IPv4 address is a 32-bit value divided into network and host portions. IP packets pass through routers with headers containing source and destination addresses, TTL, and other fields.

In this lesson, we will follow how packets acquire addresses and state at each layer, and distinguish key networking terms.
