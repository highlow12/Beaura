# One Way to Disprove an Implication

To show that the implication `P → Q` is false, find one case where `P` is true and `Q` is false. A case where `P` is false does not disprove the implication because the condition does not apply.

For example, “if a number is divisible by 4, then it is even” is true. Its converse, “if a number is even, then it is divisible by 4,” is false for `2`: it satisfies the antecedent of being even but not the consequent of being divisible by 4.

A common mistake is reading an implication as a two-way claim: “if `P`, then `Q`, and if `Q`, then `P`.” The converse needs its own counterexample. To disprove the original implication, start with a case where the antecedent is true.
