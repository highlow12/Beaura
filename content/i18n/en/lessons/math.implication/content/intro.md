# Reading Conditionals as Logical Expressions

The implication `P → Q` expresses the condition “if `P`, then `Q`.” `P` is the antecedent and `Q` is the consequent. The implication is false only when the antecedent is true and the consequent is false. If the antecedent is false, the condition has not been violated, so the implication is considered true.

For example, a day when it does not rain does not disprove “if it rains, the road gets wet.” To disprove it, you would need to find a case where it rains but the road does not get wet.
