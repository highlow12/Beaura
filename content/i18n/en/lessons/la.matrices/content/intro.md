# Arranging Numbers in a Rectangle

A matrix arranges numbers in a grid of rows and columns. An `m × n` matrix has `m` rows and `n` columns, and element `Aᵢⱼ` is in row `i` and column `j`.

A matrix's shape determines which operations are possible. If vectors are written as columns, a matrix can act like a function that maps one set of coordinates to another.
