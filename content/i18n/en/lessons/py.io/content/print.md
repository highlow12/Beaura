# Print Values with print()

`print()` displays the value inside its parentheses on the screen. It can print strings, numbers, and variable values.

~~~python
name = "Ada"
print("Hello")
print(name)
~~~

Each `print()` call ends with a newline. When you pass several values separated by commas, it puts a space between them and prints them on one line by default.

~~~python
score = 95
print("score:", score)
# score: 95
~~~

`print()` displays values on the screen, but does not receive user input. The `input()` function, covered next, handles input.
