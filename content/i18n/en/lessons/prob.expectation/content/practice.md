# Fair games and expected net gain

Multiply each prize by its probability and add the results to find the expected net gain for one game. An expected value of 0 describes a fair game with a long-run average gain of 0; it does not mean each individual game has a result of 0.

Use consistent units and a consistent baseline. Treating costs as negative values lets expected value combine gains and costs automatically; adding a constant adds the same amount to every outcome.
