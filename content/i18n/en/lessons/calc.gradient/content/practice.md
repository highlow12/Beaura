# Contour Lines and the Gradient

A contour line connects points with the same value of f(x,y). At a smooth point on a contour where ∇f is not 0, the gradient is perpendicular to the contour’s tangent and points toward increasing values. This lets you read a height surface or cost function like a map.

In optimization, gradient descent moves in the direction opposite the gradient to find a way to reduce the function value. If the learning rate is too large, it may overshoot the minimum or increase the function value; if it is too small, progress is slow.
