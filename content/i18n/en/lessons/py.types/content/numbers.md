# Numbers and Arithmetic Operations

An `int` is a number without a decimal point, and a `float` is a number with a decimal point. Values of both types can be used in arithmetic operations.

| Operator | Meaning | Example |
| ------ | ------- | ------- |
| `+` | Addition | `2 + 3` is `5` |
| `-` | Subtraction | `5 - 2` is `3` |
| `*` | Multiplication | `2 * 3` is `6` |
| `/` | Division | `7 / 2` is `3.5` |
| `//` | Floor quotient | `7 // 2` is `3` |
| `%` | Remainder | `7 % 2` is `1` |
| `**` | Exponentiation | `2 ** 3` is `8` |

`/` calculates the result of division, while `//` keeps only the quotient. For positive numbers, `//` looks like it drops the decimal part. Use `%` to get the remainder. The value to the right of `**` tells how many times to multiply.

Also consider the type of the result. For example, `7 / 2` returns the `float` value `3.5`. Parentheses make it clear which part to calculate first.
