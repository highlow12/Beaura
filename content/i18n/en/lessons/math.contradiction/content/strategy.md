# Reframing a Claim So a Contradiction Can Be Found

A proof by contradiction does not merely point out that a result seems strange; it shows that a negated assumption cannot coexist with an established condition. Before starting, write the negation of the goal precisely and decide which definition or theorem it will conflict with.

For example, suppose “there exists a largest integer `N`.” Then `N + 1` is also an integer and `N + 1 > N`. This directly contradicts the assumption that `N` is the largest, so no such `N` exists.

A common mistake is to call any result that seems counterintuitive a contradiction. At the end, state exactly “which assumption” conflicted with “which established fact,” and return to the original conclusion by explaining that the assumption is false.
