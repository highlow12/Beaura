# A Value Approached Nearby

Rather than looking only at the value when x equals a, a limit limₓ→ₐ f(x) describes the value f(x) approaches as x gets arbitrarily close to a. The limit can exist even if the function is undefined at x=a.

The left-hand limit is approached from the left, and the right-hand limit from the right. The two-sided limit exists only if these values are equal; the function value f(a) may differ from the limit.
