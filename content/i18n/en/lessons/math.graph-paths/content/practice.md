# Calculating Path Length

In a weighted graph, a path's length is the sum of the weights of the edges it visits. Counting vertices and adding edge costs are different measurements, so read the problem's definition first.

If the edge from `A` to `B` has weight 3 and the edge from `B` to `C` has weight 5, the path length from `A` to `C` is 8. When comparing paths, keep the same start and goal, and list the vertices in order so you do not miss a direction or edge.
