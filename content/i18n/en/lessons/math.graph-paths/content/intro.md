# Moving Through Vertices

A walk is a sequence of vertices connected by edges, and it may repeat vertices or edges. A path usually means a simple route that does not repeat vertices. A cycle is a closed path that starts and ends at the same vertex without repeating its intermediate structure.

When discussing connectivity, the key question is whether a path exists between vertices. In a directed graph, you cannot travel against an edge's direction, so path existence can differ even for the same set of vertices.
