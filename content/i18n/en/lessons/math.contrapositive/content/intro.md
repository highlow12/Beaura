# Starting from the Negation of the Conclusion

`P → Q` and its contrapositive `¬Q → ¬P` always have the same truth value. So if the original implication is hard to prove directly, you can use a contrapositive proof: assume `Q` is false and show that `P` is also false.

To prove “if `n²` is odd, then `n` is odd,” use the contrapositive “if `n` is even, then `n²` is even.” Write the even number as `2k`; its square is `4k² = 2(2k²)`, which directly proves the contrapositive.
