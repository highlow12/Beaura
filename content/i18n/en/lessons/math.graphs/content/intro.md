# Representing Relationships with Lines

A graph consists of a set of vertices and a set of edges connecting them. It is used to model objects and their relationships, such as people and friendships or cities and roads.

An edge in an undirected graph can be traversed in either direction; an edge in a directed graph has a specified source and destination. Graph types can also differ based on whether multiple edges connect the same pair of vertices or an edge loops back to itself.
