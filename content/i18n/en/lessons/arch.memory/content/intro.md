# SRAM and DRAM

Storing large amounts of data requires memory larger than registers, but it is not practical to build every storage cell like a register.

SRAM keeps its state with a circuit similar to a flip-flop, making it fast but large in area. DRAM stores bits as charge in capacitors, making it dense but requiring periodic refresh.

The goal of this lesson is not just to memorize terms, but to explain how inputs are represented and what hardware path produces the result.
