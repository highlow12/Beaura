# One Output for Each Input

A function `f: A → B` assigns exactly one output to every input in its domain `A`. It is not a function if one input maps to two outputs, but different inputs are allowed to map to the same output.

`B` is called the codomain, while the set of outputs actually used is called the range. The range can be a subset of the codomain, so do not treat the two terms as interchangeable.
