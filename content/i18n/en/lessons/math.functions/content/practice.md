# Injective, Surjective, and Bijective

An injective function maps different inputs to different outputs. A surjective function produces every value in the codomain at least once.

A function is bijective if it is both injective and surjective. In a bijection, inputs and outputs are paired one-to-one, so an inverse function can be formed. In an arrow diagram, check how many arrows enter each output and whether any codomain values are unused.
