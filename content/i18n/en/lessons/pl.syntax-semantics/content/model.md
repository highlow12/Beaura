# Static and Dynamic Semantics

Static semantics describes constraints that can be checked from source code without running it. Whether names are declared, types are compatible, and access rules are followed can be checked during compilation. Dynamic semantics describes results determined by actual inputs and execution state.

Language specifications can describe semantics using small-step or big-step approaches, among others. Small-step semantics lists individual execution transitions. Big-step semantics directly describes how an expression evaluates to its final value.
