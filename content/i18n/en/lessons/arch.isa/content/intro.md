# Instructions and the ISA

An instruction format must be defined so that a line of addition in source code can become a bit pattern the CPU understands.

An ISA (Instruction Set Architecture) is the CPU contract visible to programs, including instruction types, registers, addressing modes, and the memory model. An instruction usually contains an opcode and operand information.

The goal of this lesson is not just to memorize terms, but to explain how inputs are represented and what hardware path produces the result.
