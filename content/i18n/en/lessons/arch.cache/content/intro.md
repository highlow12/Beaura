# Cache and Locality

Waiting for the speed difference between the CPU and memory on every access would increase running time, so recently used data is copied nearby.

A cache is a layer that stores likely-to-be-used memory blocks in faster storage. Temporal locality is the tendency to reuse the same data; spatial locality is the tendency to access nearby addresses together.

The goal of this lesson is not just to memorize terms, but to explain how inputs are represented and what hardware path produces the result.
