## Bounded and General Cases

The general halting problem is undecidable, but if a bound on the number of execution steps is supplied as input, a decider can simulate the program only up to that bound. Restricting the input format or set of programs can change whether a problem is decidable.

The halting-problem result does not mean that all program analysis is useless. Analyses with a clearly limited scope, such as a particular language grammar, resource bound, or static rule, can still provide useful guarantees.
