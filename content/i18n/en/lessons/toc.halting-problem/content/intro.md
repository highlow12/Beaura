# Can We Predict Whether Every Program Halts?

The halting problem asks, given an arbitrary program P and input x, whether P(x) will eventually stop. Since Turing machines can represent any program, this is a classic example that reveals the limits of computation.

The key point is that observing a program for a long time cannot prove that it will never stop. Not halting for one second or one year does not rule out halting later.
