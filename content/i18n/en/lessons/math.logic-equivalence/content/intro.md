# Expressions with the Same Truth Values

Two logical expressions are logically equivalent when they have the same truth value for every input combination. Equivalent expressions produce the same result in conditionals, circuits, and search queries, even if they look different.

A common transformation is De Morgan's law. ¬(P ∧ Q) is equivalent to ¬P ∨ ¬Q, and ¬(P ∨ Q) is equivalent to ¬P ∧ ¬Q. When negation moves inside the parentheses, AND and OR switch places.
