# The Roles of the Two Steps

The inductive step proves the implication “if `P(k)` is true, then `P(k + 1)` is true.” This implication and the base case `P(1)` together start the chain through `P(2)`, `P(3)`, and so on.

To prove `1 + 2 + … + n = n(n + 1)/2`, for example, assume the formula for `P(k)` and add `k + 1` to both sides to derive the formula for `P(k + 1)`. Mention both the base case and the inductive step in the conclusion.
