# Modules Divide Code into Files

A module is a single file containing Python code. Putting functions and constants into modules by feature lets you split a large program across multiple files.

`import math` imports the math module. Access a name in it by writing the module name followed by a dot, as in `math.sqrt(9)`. `math.ceil(2.1)` returns 3, the smallest integer greater than or equal to 2.1.
