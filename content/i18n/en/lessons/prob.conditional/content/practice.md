# The multiplication rule and direction

Rearranging the conditional probability formula gives the multiplication rule P(A∩B)=P(A|B)P(B). Reversing the events can change the expression to P(B|A), so read both sides of the bar carefully.

For card or test problems, put the number of cases that satisfy the condition in the denominator, then put the number that also satisfy the event of interest in the numerator. Marking the condition in the wording helps avoid reversing the direction.
