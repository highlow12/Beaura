# Multiplexers

Inside a CPU, there are many points where only one of several calculation results should be sent to the next stage.

A multiplexer (MUX) is a combinational circuit that uses a select signal to pass one of several data inputs to the output. A MUX with 2^n inputs usually needs n select bits.

The goal of this lesson is not just to memorize terms, but to explain how inputs are represented and what hardware path produces the result.
