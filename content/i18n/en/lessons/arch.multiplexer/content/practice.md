## Follow the Select Signal

The candidate values in a multiplexer are **data inputs**; the signal that chooses one input is the **select signal**; the line carrying the selected value is the **output**.

In a 2:1 multiplexer with D0=0 and D1=1, the output is D0 (0) when select=0, and D1 (1) when select=1. The select signal does not calculate new data; it chooses which input path reaches the output.
