# Files, Directories, and File Systems

Block numbers alone make it difficult to locate user files and apply permissions, so the operating system provides names and structure.

A file system manages file-content blocks, metadata such as size, owner, and permissions, and the mappings from directory names to files. A directory is a special namespace that contains files.

In this lesson, we will follow which resources an operating-system abstraction hides and where it enforces boundaries and checks.
