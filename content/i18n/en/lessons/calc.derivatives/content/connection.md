# Predicting Nearby Changes with Derivatives

The derivative at a point is the slope used to approximate the function with a line near that point. If `x` changes slightly from `a`, the change `f(a+Δx)−f(a)` can be approximated by `f′(a)Δx`. The units of the derivative are output units divided by input units.

For example, for `f(x)=x²` at `a=3`, `f′(3)=6`. If `x` changes from `3` by `0.1`, the change is approximated as `6×0.1=0.6`; the actual change is `3.1²−3²=0.61`. The smaller the change, the closer the tangent-line approximation.

Do not confuse a derivative value with a function value. `f(3)=9` and `f′(3)=6` are different quantities. A derivative of 0 means the function is momentarily flat at that point, not necessarily that it is a maximum or minimum. For example, `f(x)=x³` has a derivative of 0 at `x=0`, but no extremum there.
