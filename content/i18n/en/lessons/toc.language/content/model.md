# String Operations

The length of a string is its number of symbols. Concatenation joins two strings by appending the right string to the left. The length of `uv` is `|u| + |v|`, and concatenating ε on either side leaves the original string unchanged.

Operations such as concatenation, union, and intersection also apply to languages. For example, `L = {0, 1}` is a language of length-1 strings, and `LL` contains the length-2 strings `00`, `01`, `10`, and `11`. A set records a string only once even if it can be generated in multiple ways.
