# From Symbols to Languages

A formal language is a set of strings defined by their form and rules rather than their meaning. An alphabet (Σ) is a finite set of available symbols, and a string is a finite sequence of those symbols. A string with no symbols is written as the empty string ε.

A language is the set of strings over an alphabet that satisfy its rules. The string `101` and the language that determines whether to include `101` are different objects; this distinction is the starting point for understanding automata and grammars.
