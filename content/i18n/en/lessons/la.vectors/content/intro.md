# Combining Magnitude and Direction

Unlike a scalar, which has only magnitude, a vector has both magnitude and direction. Writing a plane vector in components such as `(x, y)` lets us represent the difference between endpoints, displacement, and velocity in the same way.

Vectors with the same components and direction are considered the same free vector even if they start at different locations. The first component describes the change along the x-axis, and the second describes the change along the y-axis.
