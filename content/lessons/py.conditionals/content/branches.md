## if, elif, else는 위에서부터 확인한다

여러 조건이 이어지면 Python은 위에서부터 차례로 검사하고 **처음으로 참이 된 한 분기만** 실행합니다. 그 분기가 실행되면 뒤의 `elif`와 `else`는 더 확인하지 않습니다.

~~~python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
else:
    grade = "C"
~~~

위 코드는 첫 조건은 거짓이고 두 번째 조건은 참이므로 `grade`가 `"B"`가 됩니다. 범위 조건을 설계할 때는 더 구체적이거나 높은 경계를 먼저 검사해야 의도한 분기에 도달합니다.
