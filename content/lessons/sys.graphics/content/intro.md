# 이미지와 장면을 표현하는 두 관점

컴퓨터 그래픽스는 계산으로 이미지와 화면을 만드는 분야입니다. 이미 만들어진 화면을 저장하는 관점과, 화면을 만들 장면을 기술하는 관점을 구분하면 전체 흐름을 이해하기 쉽습니다.

**래스터 이미지**는 화면을 작은 픽셀 격자로 나누고 각 픽셀의 색을 저장합니다. RGB 색상은 보통 빨강·초록·파랑 채널의 값으로 표현하며, 세 채널을 조합해 다양한 색을 만듭니다.

**벡터 그래픽**과 3D 장면은 점, 선, 도형 같은 기하 정보를 저장하고 필요할 때 픽셀 결과를 계산합니다. 확대할 때 기존 픽셀을 그대로 늘리는 래스터 이미지와 달리 도형을 새 해상도에 맞춰 다시 그릴 수 있습니다.
