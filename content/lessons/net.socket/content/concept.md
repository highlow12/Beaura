## 작동 방식

서버 소켓은 연결 요청을 대기하는 리스닝 소켓과 실제 클라이언트별 연결 소켓을 구분합니다. 운영체제는 소켓 상태와 버퍼를 유지하고 전송 계층에 데이터를 넘깁니다.

### 예시로 확인하기

웹 서버는 443 포트에 bind한 뒤 accept로 여러 연결을 얻습니다. 각 연결의 요청을 읽고 응답을 쓴 다음 keep-alive나 close 정책을 적용합니다.

### 설계에서의 선택

소켓 추상화는 응용 개발을 단순하게 하지만 타임아웃·부분 read/write·동시 연결 수를 관리해야 합니다. 블로킹과 이벤트 기반 API 선택도 서버 구조에 영향을 줍니다.
