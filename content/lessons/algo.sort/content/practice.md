## 알고리즘 선택과 비용

선택 정렬은 매 위치에 들어갈 최소값을 찾아 한 번 교환하고, 병합 정렬은 정렬된 작은 범위를 합치며 문제를 나눕니다. 기본 아이디어가 달라서 입력 크기와 메모리 조건에 따라 적합성이 달라집니다.

입문 단계에서는 O(n²) 비교가 반복되는 알고리즘과 O(n log n) 규모로 나누어 처리하는 알고리즘의 차이를 구분하는 데 집중하세요.

버블 정렬 코드를 읽을 때 `values[j]`와 `values[j + 1]`은 이웃한 두 값입니다. `values[j], values[j + 1] = values[j + 1], values[j]`는 두 값을 동시에 교환하는 Python 다중 대입입니다. `for i in range(len(values))` 안에서 `range(len(values) - 1 - i)`만큼 이웃을 비교하면, 매 패스마다 오른쪽 끝에 이미 확정된 칸을 다시 검사하지 않습니다. 예를 들어 `[3, 1, 2]`의 첫 패스에서 3과 1, 이어서 3과 2를 교환하면 `[1, 2, 3]`입니다.
