# 분포 선택은 데이터 생성 과정을 묻는다

분포 이름을 모양만 보고 고르지 말고 관측값이 어떻게 만들어졌는지 확인하세요. 한 번의 성공·실패면 Bernoulli, 고정된 횟수의 독립 시행에서 성공 횟수를 세면 Binomial, 연속 측정값의 오차를 다루면 Normal 모델을 검토합니다.

예를 들어 불량품이 나올 확률이 매번 `0.05`로 같고 검사 20회가 독립이라면 불량품 수 `X`는 `Binomial(n=20,p=0.05)`로 모델링합니다. 반대로 검사마다 확률이 달라지거나 검사 결과가 서로 영향을 주면 같은 이항 공식을 바로 적용할 수 없습니다.

자주 하는 오해는 0과 1로 기록된 자료라면 언제나 이항분포라고 생각하는 것입니다. 이항분포에는 고정된 `n`, 두 결과, 독립성, 일정한 성공 확률이 모두 필요하며, 히스토그램이 종 모양이라는 이유만으로 정확한 정규분포라고 단정할 수도 없습니다.
