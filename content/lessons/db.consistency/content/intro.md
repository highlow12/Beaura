# 복제본들이 언제 같은 값을 볼까

일관성(consistency)은 여러 읽기와 복제가 데이터 상태를 어떤 규칙으로 관찰하게 할지를 말합니다. 강한 일관성은 쓰기가 성공한 뒤 다음 읽기가 최신 값을 보도록 요구하는 모델이고, 최종 일관성은 쓰기 직후 일부 replica가 잠시 이전 값을 보여도 시간이 지나 수렴하는 모델입니다.

강한 모델은 사용자 경험과 데이터 의미를 단순하게 만들지만 노드 간 확인과 네트워크 지연의 비용을 치릅니다. 최종 일관성은 지연과 가용성에 유리할 수 있지만, 중복 이벤트·오래된 읽기·충돌 병합을 애플리케이션이 감당해야 합니다.
