## while과 반복 중단

`while`은 조건이 `True`인 동안 같은 블록을 반복합니다. 조건에 쓰인 값이 반복 안에서 변하지 않으면 끝나지 않을 수 있으므로, 매 회차 뒤 조건이 어떻게 달라지는지 추적해야 합니다.

~~~python
count = 0
while count < 3:
    count += 1
~~~

`break`를 만나면 남은 반복 조건과 관계없이 가장 가까운 반복문을 즉시 빠져나옵니다. 반복 문제에서는 **현재 반복 변수 → 본문 실행 → 다음 조건 검사** 순서를 따라가면 종료 시점을 판단하기 쉽습니다.
