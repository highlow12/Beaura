# 표로 표현하는 관계

관계 모델에서 relation은 같은 속성 집합을 가진 tuple들의 집합이며, 실무에서는 테이블로 표현합니다. tuple은 한 행의 레코드이고 attribute는 한 열의 이름과 의미입니다. 각 attribute는 허용되는 값의 범위인 domain을 가집니다.

관계는 수학적으로 행의 순서가 의미를 갖지 않는 집합으로 생각합니다. DBMS가 결과를 특정 순서로 보여 주더라도 `ORDER BY`를 명시하지 않으면 그 순서에 의존해서는 안 됩니다. NULL은 0이나 빈 문자열과 다른 “알 수 없음 또는 없음”의 표시입니다.
