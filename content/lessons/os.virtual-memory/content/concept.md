## 작동 방식

가상 주소를 고정 크기 페이지 번호와 오프셋으로 나눕니다. 페이지 테이블이 페이지 번호를 프레임 번호로 바꾸고, 없는 페이지는 페이지 폴트를 일으켜 보조 저장장치에서 가져올 수 있습니다.

### 예시로 확인하기

프로세스가 4GB 주소 공간을 보더라도 실제로 사용하지 않는 페이지는 RAM에 없을 수 있습니다. 처음 접근할 때 페이지 폴트가 나고 운영체제가 프레임을 배정합니다.

### 설계에서의 선택

가상 메모리는 보호·공유·오버커밋을 가능하게 하지만 주소 변환과 페이지 폴트는 비용이 큽니다. RAM이 부족해 폴트가 반복되면 스래싱이 발생할 수 있습니다.
