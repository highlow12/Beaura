## 연속 배치와 인덱스 계산

배열의 핵심 장점은 같은 크기의 원소를 연속된 위치에 둘 수 있다는 점입니다. 시작 위치와 원소 크기를 알면 인덱스 `i`의 위치를 `시작 위치 + i × 원소 크기`처럼 바로 계산할 수 있습니다.

예를 들어 원소 하나가 4바이트라면 인덱스 0, 1, 2, 3의 시작 오프셋은 각각 0, 4, 8, 12바이트입니다. 그래서 임의의 인덱스에 접근할 때 앞의 원소를 차례로 지나갈 필요가 없습니다.

이 성질이 배열의 빠른 인덱스 접근을 설명합니다. 반대로 중간 삽입·삭제에서는 연속성을 유지하기 위해 여러 원소를 옮길 수 있습니다.
