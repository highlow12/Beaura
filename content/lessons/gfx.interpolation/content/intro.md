# 삼각형 안의 값을 추정하기

삼각형의 세 정점에 색이나 UV 같은 속성이 주어지면 fragment 위치의 값을 매번 별도로 저장하지 않고 정점 값에서 보간할 수 있습니다. 바리센트릭 좌표는 한 점을 세 정점의 가중합으로 나타내며, 내부 점에서는 세 가중치가 보통 0 이상이고 합이 1입니다.

가중치가 `(1, 0, 0)`이면 첫 정점의 값이고, `(1/3, 1/3, 1/3)`이면 세 정점의 평균에 해당합니다. 따라서 색 `(1,0,0)`, `(0,1,0)`, `(0,0,1)`을 꼭짓점에 놓으면 삼각형 내부에서 색이 연속적으로 변합니다.
