# 점과 방향을 같은 변환에 넣기

동차좌표의 마지막 성분은 평행이동이 무엇을 움직여야 하는지를 표시합니다. 2차원 평행이동 (3,2)을 행렬로 쓰면

```text
T = [[1, 0, 3],
     [0, 1, 2],
     [0, 0, 1]]
```

점 (4,1,1)에 T를 적용하면 (7,3,1)이 되지만, 방향 (1,0,0)에 적용하면 (1,0,0) 그대로입니다. 점은 위치이므로 이동하고, 방향은 두 위치의 차이이므로 같은 이동이 양쪽에서 상쇄되어야 합니다.

여러 변환은 오른쪽 행렬부터 먼저 적용됩니다. 열벡터 convention에서 T R p는 p를 먼저 R로 회전한 뒤 T로 평행이동한다는 뜻입니다. w=1인 점과 w=0인 방향을 섞거나 곱셈 순서를 거꾸로 읽으면 모델이 회전한 뒤 엉뚱한 위치로 이동하는 문제가 생깁니다.
