# 한 값이 다른 값을 결정한다

함수적 종속 `X → Y`는 두 행의 X 값이 같으면 Y 값도 같아야 한다는 제약입니다. 예를 들어 `student_id → student_name`은 한 학생 ID가 하나의 이름을 결정한다는 뜻입니다. X를 determinant, Y를 dependent라고 부릅니다.

후보 키는 relation의 모든 속성을 결정하는 최소 집합이므로 함수적 종속과 직접 연결됩니다. 한 테이블에 학생 ID와 과목 ID, 학생 이름을 함께 두고 학생 이름이 ID에만 종속되면, 학생 이름이 등록 행마다 반복되는 구조가 됩니다.
