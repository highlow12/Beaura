# 실행 중 메모리 영역

스택은 함수 호출의 프레임을 후입선출 순서로 관리하는 데 적합합니다. 프레임에는 매개변수, 지역 변수, 반환 주소 같은 실행 정보를 둘 수 있으며 호출이 끝나면 보통 한꺼번에 회수됩니다.

힙은 호출 순서와 무관하게 살아 있어야 하는 객체를 동적으로 보관하는 영역입니다. 힙 객체는 함수 호출이 끝난 뒤에도 참조를 통해 접근할 수 있으며, 더 이상 필요하지 않다는 사실만으로 즉시 사라지지는 않습니다. 수동 메모리 관리에서는 적절한 시점에 해제해야 하고, 추적형 가비지 컬렉터는 실행 루트에서 도달할 수 없어진 객체를 회수 대상으로 삼습니다.
