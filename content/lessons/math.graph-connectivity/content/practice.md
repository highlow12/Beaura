# 연결을 끊는 간선 찾기

bridge(단절 간선)는 제거했을 때 그래프의 connected component 수를 늘리는 간선입니다. 사이클 안의 간선은 다른 우회 경로가 있어 보통 bridge가 아니지만, 트리의 모든 간선은 bridge입니다.

연결성을 확인할 때는 한 정점에서 시작해 연결된 이웃을 표시하고, 새로 표시한 정점의 이웃도 반복해서 살핍니다. 예를 들어 A-B-C가 이어지고 D가 고립되어 있으면 A에서 시작해 A, B, C까지만 표시되므로 그래프는 연결되지 않았습니다. 아직 표시되지 않은 D에서 다시 시작하면 별도의 구성 요소를 찾습니다.
