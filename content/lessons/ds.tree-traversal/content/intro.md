# 트리를 방문하는 약속

트리 순회는 모든 노드를 정해진 순서로 한 번씩 방문하는 과정입니다. 이진 트리에서는 현재 노드와 왼쪽·오른쪽 하위 트리의 처리 순서로 순회를 구분합니다. 하위 트리 전체에 같은 규칙을 적용한 뒤 다음으로 넘어갑니다.

- **전위 순회**: 현재 노드 → 왼쪽 하위 트리 → 오른쪽 하위 트리
- **중위 순회**: 왼쪽 하위 트리 → 현재 노드 → 오른쪽 하위 트리
- **후위 순회**: 왼쪽 하위 트리 → 오른쪽 하위 트리 → 현재 노드

예를 들어 루트 A의 왼쪽 자식은 B, 오른쪽 자식은 C이고 B의 왼쪽 자식은 D라고 합시다. C와 D에는 자식이 없습니다. 전위는 A, B, D, C이고, 중위는 D, B, A, C이며, 후위는 D, B, C, A입니다. 전위에서 B의 하위 트리인 D까지 처리한 뒤 C로 넘어가는 점에 주목하세요.
