## 작동 방식

CPU는 현재 실행 모드와 권한 비트를 확인해 메모리·명령어 접근을 허용하거나 차단합니다. 사용자 프로그램이 파일이나 장치를 쓰려면 정해진 진입점을 통해 커널에 요청해야 합니다.

### 예시로 확인하기

텍스트 편집기가 디스크에 저장할 때 편집기 코드가 디스크 레지스터를 직접 만지는 대신 커널에 파일 쓰기를 요청합니다. 이 경계가 각 프로세스와 장치를 보호합니다.

### 설계에서의 선택

권한 분리는 안전성을 높이지만 모드 전환과 검사가 비용을 만듭니다. 커널에 기능을 많이 넣으면 빠를 수 있어도 오류가 전체 시스템에 미치는 영향이 커집니다.
