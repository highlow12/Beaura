# 반복 허용과 같은 대상 구분하기

기본 순열 공식 `nPr`은 서로 다른 대상을 중복 없이 고르는 상황을 전제로 합니다. 자리에 같은 대상을 다시 놓을 수 있다면 각 자리의 선택 수가 유지되어 `n^r`이 되고, 같은 모양의 대상이 여러 개라면 서로 바꿔도 새로운 배열이 아닙니다.

예를 들어 4개의 기호로 길이 3의 비밀번호를 만들 때 반복을 허용하면 `4^3=64`가지이고, 반복을 금지하면 `4P3=24`가지입니다. 문자 `A,A,B`를 배열하는 경우에는 같은 A를 구별하지 않으므로 `3!/2!=3`가지입니다.

자주 하는 실수는 반복 가능한 비밀번호에 `nPr`을 적용하거나, 같은 물건을 서로 다른 물건처럼 세는 것입니다. 각 자리에 다시 사용할 수 있는지와 대상의 이름만 다른지 모양도 같은지를 먼저 확인하세요.
