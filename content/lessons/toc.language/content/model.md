# 문자열 연산

문자열의 길이는 기호의 개수이고, 두 문자열을 잇는 연결(concatenation)은 왼쪽 문자열 뒤에 오른쪽 문자열을 붙이는 연산입니다. `uv`의 길이는 `|u| + |v|`이며, ε를 어느 쪽에 연결해도 원래 문자열이 그대로 남습니다.

언어에도 연결, 합집합, 교집합 같은 연산을 적용할 수 있습니다. 예를 들어 `L = {0, 1}`은 길이 1의 언어이고, `LL`은 `00`, `01`, `10`, `11`을 포함하는 길이 2의 언어입니다. 같은 문자열이 여러 경로로 만들어져도 집합에는 한 번만 기록합니다.
