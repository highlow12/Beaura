# 같은 데이터를 여러 노드에

복제(replication)는 하나의 데이터 변경을 여러 DB 노드에 전달해 가용성이나 읽기 처리량을 높이는 방식입니다. primary가 쓰기를 받고 replica가 변경 로그나 스트림을 따라가는 구조가 흔하며, 장애 시 replica를 새 primary로 승격할 수 있습니다.

동기 복제는 정해진 replica가 변경을 확인한 뒤 성공을 확정해 데이터 손실 가능성을 줄이지만 쓰기 지연이 커질 수 있습니다. 비동기 복제는 primary가 먼저 응답해 지연을 줄이는 대신 replica가 잠시 뒤처질 수 있어, 장애 시 최근 쓰기가 유실되거나 읽기 직후 오래된 값이 보일 수 있습니다.
