# 필요한 행과 열만 요청하기

SQL의 `SELECT`는 반환할 열을, `FROM`은 읽을 테이블을, `WHERE`는 남길 행의 조건을 지정합니다. 질의는 “각 행을 어떤 순서로 직접 방문하라”가 아니라 원하는 결과의 조건을 선언하고, DBMS가 실행 계획을 선택하게 합니다.

결과의 표시 순서가 필요하면 `ORDER BY`를 사용합니다. `WHERE`는 정렬 전에 행을 걸러내고, `SELECT` 목록은 조건을 통과한 결과에서 어떤 열을 노출할지 결정합니다. 따라서 `SELECT *`는 편리하지만 불필요한 열과 스키마 변경까지 노출할 수 있습니다.
