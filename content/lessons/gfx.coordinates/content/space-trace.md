## 한 점의 화면까지 추적하기

한 점의 숫자를 볼 때는 값보다 공간의 이름을 먼저 적습니다. 예를 들어 로컬 점이 `(1, 0, 0)`이고 모델 변환이 x 방향으로 2만큼 이동시키면 월드 점은 `(3, 0, 0)`입니다. 카메라가 x = 1에 있다면, 회전이 없다는 단순한 상황에서 뷰 점은 `3 - 1 = 2`가 됩니다. 같은 점인데도 모델·월드·뷰의 숫자가 다른 이유는 점 자체가 바뀐 것이 아니라 기준이 바뀌었기 때문입니다.

투영 뒤의 클립 좌표도 아직 픽셀이 아닙니다. 예를 들어 원근 나눗셈 뒤 NDC의 x가 `0.5`이고 뷰포트 폭이 800이면 화면 x는 `(0.5 + 1) / 2 × 800 = 600`처럼 계산됩니다. 클립 좌표에서 바로 600을 읽거나 모델 좌표와 픽셀 좌표를 비교하면 안 됩니다. `model → world → view → clip → NDC → viewport` 중 어느 단계의 값인지 확인하는 습관이 좌표 혼동을 막습니다.
