# API는 약속이다

API는 모듈이나 서비스가 다른 코드에 제공하는 이름, 입력, 출력, 오류의 약속입니다. 함수 이름과 타입만 맞아도 계약이 완성되는 것은 아닙니다. 어떤 입력을 허용하는지, 성공했을 때 무엇을 보장하는지, 실패를 어떻게 알리는지도 호출자가 알아야 합니다.

계약을 명시하면 구현과 사용자의 책임이 분리됩니다. 예를 들어 `get_page(limit)`가 `limit`을 1 이상 100 이하로 제한한다면 호출자는 그 범위를 지켜야 하고, 서비스는 성공 시 최대 100개의 항목과 다음 페이지 정보를 제공해야 합니다.

계약은 변경의 안전망이기도 합니다. 내부 알고리즘을 바꾸더라도 같은 입력에 같은 의미의 결과와 오류를 제공하면 클라이언트는 영향을 받지 않습니다. 반대로 문서에 없던 예외나 필드 의미의 변경은 작은 코드 변경처럼 보여도 API 계약을 깨뜨릴 수 있습니다.
