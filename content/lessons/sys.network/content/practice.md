## 역할을 나누는 프로토콜

**프로토콜**은 통신하는 대상들이 메시지의 형식과 처리 방법을 합의한 규칙입니다. 하나의 프로토콜이 통신의 모든 일을 맡지 않습니다. 이더넷은 같은 링크의 프레임 전달, IP는 여러 네트워크를 지나는 패킷 전달, TCP와 UDP는 프로그램 사이의 전송, HTTP는 웹 요청과 응답을 각각 담당합니다.

웹 주소를 입력하면 DNS가 이름에 대응하는 IP 주소를 찾도록 돕고, 이후 여러 계층의 프로토콜이 각자 헤더를 붙여 데이터를 전달합니다. 프로토콜을 배울 때는 “어느 범위의 대상을 연결하는가?”, “어떤 데이터 단위를 다루는가?”, “어떤 문제를 책임지는가?”를 나누어 질문하면 역할을 구분하기 쉽습니다.
