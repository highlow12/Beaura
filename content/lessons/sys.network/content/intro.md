# 장치를 연결하고 데이터를 전달하기

컴퓨터 네트워크는 여러 장치가 링크를 통해 연결되어 정해진 규칙으로 데이터를 교환하는 시스템입니다. 노트북과 서버처럼 통신의 양 끝에서 데이터를 만들고 소비하는 장치를 **호스트**라고 합니다. 호스트 사이에는 스위치와 라우터 같은 중간 장치가 데이터를 다음 구간으로 전달합니다.

긴 데이터는 보통 **패킷**이라는 작은 단위로 나뉘어 전송됩니다. 패킷에는 전달에 필요한 헤더와 실제 내용인 페이로드가 들어갈 수 있습니다. 모든 패킷이 순서나 재전송 정보를 갖는 것은 아니며, 필요한 제어 정보는 사용하는 프로토콜과 계층에 따라 달라집니다.
